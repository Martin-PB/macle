# Contributing to MACLE

Thank you for your interest in contributing.

MACLE is at an early exploratory stage. Contributions that clarify use cases, terminology, conceptual boundaries and design constraints are particularly welcome.

## Before contributing

- Search existing issues and discussions before opening a new one.
- For substantial changes, open an issue or discussion first so the direction can be agreed.
- Keep proposals focused and explain the problem they address.
- Distinguish established project decisions from hypotheses and open questions.

## Pull requests

- Describe the motivation and scope of the change.
- Keep changes focused; avoid bundling unrelated refactoring or formatting.
- Update relevant documentation when behavior, terminology or project direction changes.
- Be explicit about assumptions, limitations and unresolved questions.
